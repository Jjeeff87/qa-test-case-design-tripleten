# QA Test Case Design — TripleTen (Sprint 9)

Manual QA deliverable from the TripleTen QA Analyst Program: a full test case design matrix for a web "Place Order" checkout flow, built using industry-standard test design techniques.

## What's inside

- `Jeferson_Schneider_sprint9-QA32_EN.pdf` — complete test case matrix

## Techniques applied

- Equivalence Class Partitioning
- Boundary Value Analysis
- Cross-browser validation (Chrome, Opera)
- Structured bug tracking (Jira-style bug links per failed case)

## Scope

100+ executed test cases covering field-level validation (required fields, character limits, valid/invalid input classes) for the checkout form, with expected vs. actual results documented per case and per browser.

Part of the QA Analyst Program coursework at [TripleTen](https://tripleten.com/).
